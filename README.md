# JSCOE_Mar27

Pandas and ML deployment with Streamlit (session folder `JSPM_Hadapsar_Mar27`).

## Contents

- `1Pandas_Mar27.ipynb`: data cleaning with Pandas
- `SLR_Mar27.ipynb`: simple linear regression on `Salary_Data.csv`
- `dt_Mar27.ipynb`: decision tree
- `app.py` and `model.joblib`: a Streamlit app that serves the trained model

Open the notebooks in Jupyter or Google Colab. The csv, json and xlsx files next to them are the datasets the notebooks use.

To run the app: `pip install streamlit joblib pandas numpy scikit-learn`, then `streamlit run JSPM_Hadapsar_Mar27/app.py`.
